<p>Switch Private DNS and USB debugging from your Quick Settings panel. Choose the states each tile cycles through, or restore the previous setting automatically after a delay.</p>

<p><b>Private DNS</b></p>
<ul>
<li>Switch between Off, Auto and your chosen DNS providers.</li>
<li>Use AdGuard, Cloudflare or Quad9, or add your own hostname.</li>
<li>Choose and sort the providers included in the tile cycle.</li>
<li>Set a DNS target directly from the app.</li>
</ul>

<p><b>DNS for each connection</b></p>
<ul>
<li>Choose separate DNS targets for Wi-Fi and mobile data.</li>
<li>Add rules for individual Wi-Fi networks by name (SSID), with an optional BSSID for a specific access point.</li>
<li>Search network and DNS lists when setting up rules.</li>
<li>Turn Private DNS off while a VPN is connected and restore it afterwards.</li>
<li>Detect changes while the tile is visible or in the background.</li>
</ul>

<p><b>USB debugging</b></p>
<ul>
<li>Turn USB debugging on or off from its tile.</li>
<li>Optionally toggle Developer Options and Wireless Debugging at the same time.</li>
<li>Choose the tile's states and set an automatic return to the previous setting.</li>
</ul>

<p><b>Shortcuts and settings</b></p>
<ul>
<li>Run actions from your launcher or compatible automation apps, and pin shortcuts to the home screen.</li>
<li>Choose up to four favorites. DNS and USB share the shortcut limit shown for your device.</li>
<li>Require device unlock before either tile changes a setting.</li>
<li>Export settings, DNS entries, network rules and shortcut configuration to a backup file.</li>
<li>Use light or dark mode, with dynamic colors on Android 12 and later.</li>
</ul>

<p><b>Setup</b></p>
<p>Requires Android 10 or later and WRITE_SECURE_SETTINGS permission. The welcome flow and permission setup page guide you through granting it with ADB, Shizuku or existing root access. Root is not required when using ADB. Then add Private DNS and USB Debugging to your Quick Settings panel.</p>

<p>Background detection uses a foreground service. On Android 13 and later, notification permission is optional; Android still lists the service in its active apps area. Earlier versions require an ongoing service notification. Wi-Fi network rules need background detection and location access; the app explains the required permissions.</p>

<p>Backups restore app configuration, replacing current settings. System permissions must be granted separately on each device.</p>
